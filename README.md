# rewatched-pages

Hosts the public Privacy Policy and Terms of Service for the [Rewatched](https://github.com/catarinagf/rewatched) Android app, served via GitHub Pages.

This repo exists solely so these two documents can have a public URL without making the main app repo public. Nothing here is app source code.

- [Privacy Policy](https://catarinagf.github.io/rewatched-pages/privacy-policy.html)
- [Terms of Service](https://catarinagf.github.io/rewatched-pages/terms-of-service.html)

Edit the HTML files directly and push to `main` — GitHub Pages (once enabled in repo Settings → Pages, source: `main` branch, `/` root) redeploys automatically.
